Accessibility

Travlr Getaways aims to offer a clear and usable experience for visitors with different devices, preferences, and ways of interacting with the web.

Accessibility features

The static site includes semantic page regions, labeled form fields, descriptive image alternatives where appropriate, skip navigation, keyboard-visible focus indicators, and reduced-motion support. Form feedback is designed to help visitors identify fields that need attention.

Known scope and limitations

The site is a demonstration and has not received a formal accessibility conformance audit. Automated checks and code review cannot establish compatibility with every assistive technology, browser, or device. Some inherited visual assets and design patterns may require further evaluation.

Feedback and alternatives

If you encounter an accessibility barrier, please describe the page, the task you were attempting, and any relevant browser or assistive technology. The contact page is part of the demonstration and does not send messages, so it should not be treated as an operational support channel.
